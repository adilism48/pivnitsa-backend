# Пивница Backend


## 🛠 Процесс разработки и ветвление

В качестве основной ветки разработки (Default Branch) используется **`main`**.

### Правила работы с репозиторием:
1. **Основная ветка всегда стабильна:** Любой код в ветке `main` должен быть рабочим и готовым к развертыванию на тестовом стенде.
2. **Прямые пуши запрещены:** Вливание кода в `main` происходит только через создание **Pull Request (PR)**.
3. **Создание новых веток:**
    * Для новой функциональности создавайте ветку от `main` с префиксом `feature/`:  
      `git checkout -b feature/название-задачи`
    * Для исправления багов используйте префикс `bugfix/`:  
      `git checkout -b bugfix/описание-бага`
